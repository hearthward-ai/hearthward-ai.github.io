The basics

What is Hearthward?

A personal AI assistant designed to run around the clock on your own computer with an open model (one whose files you can download and run yourself). It is meant to remind you of deadlines, keep your schedule and draft emails for you to approve.

Can I download it?

Not yet. It is in early development. There is no download, and nobody can sign up. This site will link to the code when it is public.

Is it free?

It is planned to be free to use. You would need a capable PC with a modern graphics card; exact requirements will come with the release.

Do I need Discord?

You are meant to talk to it in a chat app, and Discord is planned first.

How is this different from ChatGPT or other assistants?

It is designed to run on your own machine with a model you run yourself, to ask before acting, and to be built around a guard against hidden instructions. It is early, so these are goals being built and tested, not finished features.

Can my family use it?

Mainly it is a personal tool. It could also be set up for family members at home, each with their own limits on what it may do and whom it may contact.

Privacy and safety

Is my data private?

Your data stays on your computer and the model runs locally. But features such as sending an email or using a chat app send that message through the service you choose, and that service can see it. See the privacy policy.

What is prompt injection?

Instructions hidden in text the assistant reads, such as a web page or an email, that try to make it do something you did not ask for. The guard tries to catch and contain these.

Does the guard make it safe?

No. It cannot promise safety. It lowers the risk and cannot remove it. It is a supporting feature, built to make the assistant safe enough to leave running. See how it works for what it does and does not do.

Will it send email without asking?

It is designed not to. Any action on your behalf asks first, and email goes only to recipients you approved. Like the rest of the guard, this is a design goal that is still being tested.

Will it read my inbox?

Not now. The Gmail connection is planned to send approved email only. Reading email would need a different Google permission, and the privacy policy would be updated first.

Will it ask for my passwords?

It is designed never to. Keys and logins stay on your machine and are entered by you.

The project

Who is building it?

Tony (GitHub: TonyC115), a university student. It is a personal engineering project, not a product or a company.

Is it open source?

The code is planned to be released under the Apache License 2.0 once a complete, tested version is ready. It is built on Hermes Agent (Nous Research), which is open source. Hearthward is not affiliated with or endorsed by Nous Research, Google or any model maker.

How do I report a security problem?

Please do not post details publicly. Use GitHub’s private “Report a vulnerability” option under the Security tab of the repository, if it is shown there. If it is not shown yet, open a short issue at the repository’s issues page asking for a private contact, with no details. See the privacy policy for the full wording.

What does the name mean?

煦坞 (xù wù) means, roughly, a warm, sheltered harbour.

Where can I follow progress?

On the roadmap page and at github.com/hearthward-ai.
