获取防护层

在你自己的电脑上安装 Hearthward 防护层。这是早期版本（v0.9.3），在 Hermes Agent 0.23.1 上测试过。

本页是英文版的中文译文，如有出入，以英文版为准。

首页 用途 开始之前 从这里开始

用途

防护层是 Hermes Agent（你在自己电脑上运行的 AI 助手）的插件（给它增加功能的小程序）。它检查助手读到的文字，在助手行动之前先问你，并检查助手发出的回复。它的主要作用是降低提示注入的风险，也就是藏在助手所读文字（例如网页或邮件）里的指令。三个部分的说明，请看工作方式。

适合谁：愿意照着一份长指南一步步做、想给 Hermes Agent 试用安全插件的人。不需要懂编程，也不需要事先装好 Hermes：指南会带你安装。

本页只是个路标。真正的分步说明在 GitHub 上的安装指南里。

开始之前

  • Hermes Agent 0.23.1。指南只针对这个版本检查过，更新的版本没有测试过。装好之后不要更新 Hermes。
  • Linux，或装有 WSL 的 Windows。WSL（Windows Subsystem for Linux）是 Windows 自带的免费功能，可以在 Windows 里运行 Linux。需要 Windows 10 2004 版或更新，或 Windows 11，指南里有开启方法。已在 Ubuntu 24.04 上测试，macOS 没有测试。
  • 一个聊天软件账号，给你的助手用，比如 Discord 或 Telegram。Hermes 会在它自己的设置过程中连上它。
  • 给 Hermes 用的 AI 模型。Hermes 在它自己的设置过程中会让你选一个：云端服务，或你电脑上的模型。
  • 约 4 GB 空闲磁盘空间和网络连接。可选的模型检查另需空间（见下）。
  • 一到两小时。大部分时间在等下载。安装 Hermes 时，大约 30 分钟里可能看不到任何进度；请耐心等，不要关掉窗口。

可选的模型检查，是让一个在你电脑上运行的小型 AI 模型，对可疑文字再看一遍。可以跳过。如果要用，需要再多约 21 GB 磁盘空间（一共约 25 GB），以及约 24 GB 空闲内存（显卡显存和普通内存加起来）。

请先阅读。这是给测试者用的早期版本，没有经过独立审计。它只在一种环境上测试过，而且聊天软件只用过模拟的 Discord 程序，没有接过真实账号，所以难免有粗糙之处。它能降低提示注入的风险，但不能消除风险，有些攻击会漏过去。重要的事请自己再确认。使用前请先看免责声明。

从这里开始

  • 安装指南一步一步，从一台空电脑到能通过自检的防护层（简体中文）

  • 源码 v0.9.3本页所说明的确切标记版本。目前没有单独的下载包或发布说明。
