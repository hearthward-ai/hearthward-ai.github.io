# Security policy

This repository is the Hearthward project website (static pages). Hearthward is pre-release software,
offered as is and without warranty; see the disclaimer on the site.

## Reporting a problem

If you find a security problem with this website (for example a script that should not be there, or
private information that is visible), please use GitHub's **Report a vulnerability** button on the Security
tab of this repository (a private advisory). Do not open a public issue for it. If you cannot use the
button, write to the public project contact listed on the website.

Expect an acknowledgement within about 7 days. This is a one-person project, so fixes are best effort.

## Supported versions

Only the live site built from main.

## Scope notes

- Never post real tokens, personal data or private messages in an issue.
- Problems in the guard software itself belong in the hearthward-guard repository.
