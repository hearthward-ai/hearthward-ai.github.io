# Contributing

This repository is the Hearthward project website (static pages). Hearthward is a one-person, pre-release
project, so replies and merges are best effort.

- **Typos, broken links, unclear wording:** a pull request or a plain issue is welcome. Keep changes small.
- **Bigger changes:** open an issue first so we can agree on it before you spend time.
- **Security problems or private information on the site:** do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **No secrets or personal data** in issues, pull requests or commit messages. Use your public GitHub identity only.
- **Checks:** pull requests run the site checks (`tools/sitecheck.py`) and a leak scan automatically.
- **Licence:** by contributing you agree your contribution is released under the project's [Apache-2.0 licence](LICENSE).
  The name, the Chinese name and the logo are not covered by it (see the README).
